# Scale by max and min

Scale by max and min

## Usage

``` r
min_max_scale(x)
```

## Arguments

- x:

  A vector of numerical values

## Value

A vector of numerical values "y" scaled by x's max and min

## Examples

``` r
min_max_scale(x = c(2, 9, 4, -5, 8, -6))
#> [1] 0.53333333 1.00000000 0.66666667 0.06666667 0.93333333 0.00000000
```
